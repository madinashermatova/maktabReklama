## Third-party assets

The Poly Haven library in the Blender MCP add-on is switched **off** (`get_addon_status` → `polyhaven: off`), so nothing was downloaded through the MCP. The three HDRIs below are Blender's own bundled studio-light HDRIs, copied from `Blender 5.3/5.3/datafiles/studiolights/world/`. Their licence file (kept as `assets/hdri/LICENSE-blender-studiolights.txt`) states: "All HDRIs are licensed as CC0. These were created by Greg Zaal (Poly Haven)." They are 1K versions, used only for the view through windows and reflections.
